\begin{itemize}
    \item We design an indirect dynamic mechanism for environments with observational pooling.
    \item The MDG process models execution errors under maximum entropy constraints.
    \item We prove that Bayesian learning converges almost surely to the true type.
    \item Perfect Bayesian equilibrium guarantees sequential implementability.
    \item Deep learning neural networks approximate the value function to solve the game.
